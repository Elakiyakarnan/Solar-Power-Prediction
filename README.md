
# Solar Power Generation Prediction Using Machine Learning

## Project Description
This project predicts solar power generation using historical weather and solar-related data with Machine Learning algorithms.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib
- Google Colab

## Machine Learning Algorithms
1. Linear Regression
2. Decision Tree Regression
3. Random Forest Regression

## Best Model
Random Forest Regression

## Model Performance
- MAE: 66.78
- RMSE: 123.07
- R² Score: 0.8959

## Features
- Weather data input
- Solar parameter input
- Solar AC output prediction
- Interactive Streamlit interface
